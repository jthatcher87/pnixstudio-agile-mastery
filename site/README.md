# PNiXStudio Agile & Scrum Mastery

Combined local PWA: all six guide modules plus the five-scenario anti-pattern diagnostic in Module 7. Originals are unchanged. Branding uses obsidian #08080f, violet #8B5CF6 and #7C3AED, and lavender accents. Green/red feedback retains its semantic meaning.

Serve this folder over localhost or HTTPS to enable the manifest and offline service worker. For example, run `python -m http.server 8765` from this folder and open http://localhost:8765. Browser installation availability varies. A direct file opening supports the app but cannot register its service worker.

Course and diagnostic progress are stored separately in this browser. Prior ambiguous shared-key data is not imported. Clearing site data clears progress. No accounts or backend are required.

Scripts, icons and icon fonts are packaged locally. After a successful first load and service worker activation the app is available offline. Educational source content was preserved; this merge is not a fresh content audit or certification endorsement.

## Ambient ribbon background
Uses the supplied AdobeStock_1915557521.mov as a muted ten-second looping background, converted to H.264 at 1440x810 and 24 fps. Source MOV is unchanged. A dark overlay preserves legibility. Background motion can be paused using the control above the course; the choice is saved locally. Reduced-motion preferences use the still frame, and playback pauses when the tab is hidden. Both media files are included in the offline cache.
