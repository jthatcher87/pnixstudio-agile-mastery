SQL field guide
Read the query in execution order: FROM / JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT.
SELECT city, COUNT(*) AS total
FROM employees
WHERE salary > 60000
GROUP BY city
HAVING COUNT(*) >= 2
ORDER BY total DESC, city ASC
LIMIT 5;
NULL: use IS NULL / IS NOT NULL.
Text: single quotes, like 'Chicago'.
Aliases: AS gives a result column a name.
Joins: match keys with ON; LEFT JOIN keeps unmatched left rows.
Portability: this course uses SQLite. SQL Server uses TOP or OFFSET/FETCH instead of LIMIT. Case sensitivity and grouping rules can vary across databases.
