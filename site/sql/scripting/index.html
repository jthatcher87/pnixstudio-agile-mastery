SQL scripting field guide
Use semicolons between statements. Each run begins with fresh fictional data. Writes within a run are visible to later statements in that same run.
-- Rehearse a targeted update
BEGIN;
UPDATE employees SET salary = salary + 1000
WHERE department_id = 1;
SELECT id, name, salary FROM employees;
ROLLBACK;
CREATE TABLE: define columns and constraints.
INSERT INTO … VALUES: add rows.
INSERT INTO … SELECT: copy query results.
UPDATE … SET … WHERE: change selected rows.
DELETE FROM … WHERE: remove selected rows.
BEGIN / COMMIT / ROLLBACK: control transactions.
CREATE VIEW: store a query.
CREATE INDEX: create an access structure.
Without WHERE, UPDATE and DELETE affect every row. Inspect targets first. Always close a transaction. A failed statement in production does not necessarily undo earlier writes; this runner discards the sandbox after an error.
SQLite dialect. SQL Server DECLARE, procedures, IF/WHILE, TRY/CATCH and GO are outside this course. Progress saves locally and does not sync between devices.
